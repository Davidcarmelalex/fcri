# NRLink within FCRI

NRLink is being developed as a flagship financial infrastructure initiative under the Fusion Civilization Research Institute (FCRI).

## Vision
Cross-border liquidity orchestration platform for premium settlement infrastructure.

## Planned Modules
- nrlink-web (public web + launch funnel)
- nrlink-admin (ops dashboard)
- nrlink-api (backend services)
- ledger engine
- settlement orchestration
- compliance workflows
- AI agent layer
