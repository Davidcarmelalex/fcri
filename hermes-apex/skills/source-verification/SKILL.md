# Source verification
Record source URL or document ID, author, publication date, retrieval time and relevant passage. Prefer primary sources; triangulate contested claims. Distinguish allegation, inference and verified fact. Flag missing or stale sources. Never invent citations. Return claim-to-source matrix and unresolved questions.
