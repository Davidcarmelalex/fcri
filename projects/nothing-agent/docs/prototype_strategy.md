# MR NOTHING Prototype Strategy

## Hardware Decision
Primary prototype hardware: Nothing Phone (2)

## OS Strategy
Phase 1 uses stock Nothing OS.

We will NOT replace the operating system initially.

### Prototype 1: MR EXECUTOR
App-layer AI execution platform using:
- voice interaction
- accessibility automation
- notification listener
- workflow execution
- backend orchestration

### Prototype 2: MR COMMAND CENTER
AI-native launcher and command experience using:
- custom launcher shell
- contextual memory
- unified dashboard
- quick automations

## Why stock OS
- faster execution
- higher demo stability
- OEM partnership optics
- lower engineering risk
- no firmware dependency risk

## Future path
If partnership progresses:
1. deeper OS integration
2. privileged services
3. firmware collaboration
4. AI-native co-designed device
